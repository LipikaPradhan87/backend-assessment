# Backend Developer Technical Assessment

## 🚀 Project Overview
This project implements a data pipeline using Docker with three services:

- Flask API (Mock Server)
- FastAPI (Data Ingestion Service)
- PostgreSQL (Database)

### 🔄 Data Flow
Flask (JSON) → FastAPI (Ingest) → PostgreSQL → API Response

---

## 🛠️ Tech Stack
- Python 3.10+
- Flask
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker & Docker Compose
